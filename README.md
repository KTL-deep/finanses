# Timur & Lera | Financial Architecture App

Семейное веб-приложение для планирования и контроля финансов с поддержкой двухфазного денежного потока (**Аванс** и **Зарплата**).

## 🚀 Быстрый запуск локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер:
   ```bash
   npm start
   ```
   Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

---

## 🐳 Деплой на отдельный сервер через Docker

1. Скопируйте проект на ваш VPS-сервер.
2. Выполните команду для сборки и запуска в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```
3. Приложение будет развернуто на порту `3000` (можно проксировать через Nginx / Caddy с SSL сертификатом).

### Сохранность данных
Все данные помесячных планов автоматически сохраняются в базу данных SQLite в папке `./data/finance.db`, которая монтируется как Docker Volume. При перезапуске или обновлении контейнера все финансовые данные сохраняются.
