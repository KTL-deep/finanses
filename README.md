# Timur & Lera | Financial Architecture App

Семейное веб-приложение нового поколения для планирования и контроля финансов с поддержкой двухфазного денежного потока (**Фаза 1: Аванс 10-го** и **Фаза 2: Зарплата 25-го**), встроенной авторизацией, интерактивной аналитикой и современными компонентами от **shadcn/ui** и **ui.corr.sh**.

---

## 🛠 Технологический стек

- **Фронтенд**: React 18, TypeScript, Vite 6, Tailwind CSS, Radix UI Primitives, Lucide Icons, Framer Motion / Motion.
- **UI Реестр (`ui.corr.sh`)**:
  - `DataTable` — таблицы продуктов, желаний и внеплановых трат с умным поиском, сортировкой, CSV-экспортом и защитой деструктивных действий.
  - `AnimatedButtons` / `AnimatedButton` — анимированные кнопки с состояниями загрузки и подтверждения.
  - `FileManager` — файловый менеджер чеков, договоров и выписок с поддержкой Drag & Drop.
  - `StatusPage` — страница доступности сервисов, SQLite и вебхуков банка.
- **Бэкенд**: Node.js (Express), SQLite (`node:sqlite` DatabaseSync), PBKDF2-хэширование паролей, сессионные куки.

---

## ✨ Ключевые возможности

1. **Двухфазное финансовое планирование**:
   - **Фаза 1 (10-е число — Аванс)**: учет авансов Тимура и Леры, оплата ЖКУ, погашение кредитной карты и расчет остатка.
   - **Фаза 2 (25-е число — Зарплата)**: учет основных выплат, оплата аренды и расчет свободных средств для целей.
2. **Финансовые цели и доли накоплений**:
   - Автоматическое распределение свободного остатка по фондам с возможностью скрытия сумм (режим инкогнито).
3. **Таблицы данных (`ui.corr.sh DataTable`)**:
   - Продукты, Wish-лист (Хотелки), Внеплановые траты с фильтрацией, пагинацией и экспортом в CSV.
4. **Хранилище документов (`ui.corr.sh FileManager`)**:
   - Загрузка и структурирование чеков, договоров и выписок по папкам.
5. **Импорт выписок Т-Банка**:
   - Разбор CSV-файлов банка с авто-распределением по категориям.
6. **Историческая статистика и графики**:
   - Визуализация динамики доходов, расходов и накоплений по месяцам (Chart.js).
7. **Мониторинг состояния (`ui.corr.sh StatusPage`)**:
   - Интерактивный экран статуса сервера, БД SQLite и интеграций.

## 🚀 Запуск и разработка

### Режим разработки (Vite + Express Backend одновременно):
```bash
npm install
npm run dev
```
- Фронтенд (HMR): [http://localhost:5173](http://localhost:5173)
- Бэкенд API: [http://localhost:3000](http://localhost:3000)

### Сборка и запуск продакшена:
```bash
npm run build
npm start
```
Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

## 🐳 Деплой через Docker

```bash
docker compose up -d --build
```
