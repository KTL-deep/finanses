# Timur & Lera | Financial Architecture App

Семейное веб-приложение премиум-класса для планирования и контроля финансов с поддержкой двухфазного денежного потока (**Аванс** и **Зарплата**), встроенной авторизацией, ролевым доступом к скрытым целям и аналитикой.

---

## ✨ Ключевые возможности

- 🔐 **Встроенная авторизация и Личный кабинет**:
  - Персональные аккаунты для **Тимура** (`timur`) и **Леры** (`lera`).
  - Защищенные `HttpOnly` сессии на 30 дней и шифрование паролей через `PBKDF2`.
  - Удобный Личный кабинет прямо в шапке с функцией безопасной смены пароля.
  - Защита финансовых эндпоинтов от неавторизованного доступа (`HTTP 401`).

- 🎯 **Ролевой доступ к скрытым целям**:
  - **Тимур (Администратор)**: видит все цели (включая скрытые 🔒), их названия, прогресс накопления и может управлять ими в настройках месяца.
  - **Лера**: скрытые цели **полностью скрыты из списка**, но их денежные суммы **математически вычитаются** из доступного бюджета. Баланс сходится до рубля без раскрытия деталей сюрпризов.

- 🎁 **Wish-лист с привязкой к авторам и аналитикой**:
  - Каждая хотелка фиксирует своего автора (`👤 Тимур` / `🌸 Лера`).
  - В разделе **«Статистика 📊»** доступен отдельный блок аналитики хотелок по авторам (количество, общие суммы и процент исполнения).

- 📥 **Автоматизация и импорт выписок Т-Банка**:
  - Загрузка `.csv` / `.txt` выписок Т-Банка в раздел продуктов с автоматическим распознаванием категории супермаркетов.

## 🔐 Аккаунты по умолчанию

При первом запуске сервер автоматически создаёт два аккаунта:

| Имя пользователя | Логин по умолчанию | Пароль по умолчанию | Роль / Права |
| :--- | :--- | :--- | :--- |
| **Тимур** | `timur` | `timur` | Администратор (видимость скрытых целей) |
| **Лера** | `lera` | `lera` | Семейный доступ |

> 💡 **Рекомендация:** После первого входа откройте Личный кабинет (кнопка с вашим именем в шапке) и смените пароль на персональный.

## 🚀 Быстрый запуск локально

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер в режиме разработки:
   ```bash
   npm run dev
   ```
   или в обычном режиме:
   ```bash
   npm start
   ```
   Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

## 📱 Сборка Android APK (Windows)

Для сборки нужны JDK 21 (`JAVA_HOME`) и Android SDK с платформой Android 36. В `android/local.properties` задайте `sdk.dir` — путь к SDK на вашем компьютере. После установки инструментов откройте новый терминал.

```bash
npm run build:apk
```

Готовый установочный файл: `android/app/build/outputs/apk/debug/app-debug.apk`. Это отладочная сборка для прямой установки, не для публикации в Google Play. Минимальная версия — Android 7.0.

Приложение по умолчанию подключается к `https://fin.ktl-server.ru`; адрес можно изменить на экране входа.

## 🐳 Деплой и обновление на VPS (через Docker)

### Первоначальный запуск
1. Скопируйте проект на ваш VPS-сервер.
2. Соберите и запустите контейнер:
   ```bash
   docker compose up -d --build
   ```
   Приложение будет развернуто на порту `3000`.

### Обновление на сервере
База данных `data/finance.db` исключена из отслеживания Git, поэтому обновление проходит безопасно и без конфликтов с вашими реальными финансами:

```bash
cd /root/finanses
git pull
docker compose up -d --build
```

## ⚙️ Переменные окружения (Environment Variables)

Вы можете переопределить стандартные настройки через файл `.env` или секцию `environment` в `docker-compose.yml`:

- `PORT` — порт приложения (по умолчанию `3000`).
- `TIMUR_PASSWORD` — пароль первоначальной инициализации для Тимура (по умолчанию `timur`).
- `LERA_PASSWORD` — пароль первоначальной инициализации для Леры (по умолчанию `lera`).

---

## 💾 Сохранность данных

Все данные (помесячные планы, финансовые цели, история трат, пользователи и их пароли) автоматически сохраняются в SQLite БД `./data/finance.db`, которая монтируется как Docker Volume. При перезапуске или обновлении контейнера все данные сохраняются.
